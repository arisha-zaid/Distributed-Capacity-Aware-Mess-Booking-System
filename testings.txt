True Load Balancer Simulation (Advanced)

If you want to simulate a real load balancer:

Install nginx:

sudo apt install nginx

Edit config:

sudo nano /etc/nginx/sites-available/default

Inside server {} block:

location /bookings {
    proxy_pass http://backend;
}

upstream backend {
    server localhost:5000;
    server localhost:5001;
}

Restart:

sudo service nginx restart

Now send requests to:

http://localhost/bookings

Nginx will randomly distribute between 5000 and 5001.

How To Verify It’s Hitting Both Servers
Add this inside your server.js:
console.log(`Request handled by PORT ${process.env.PORT}`);
When you run test, you should see logs alternating between:
PORT 5000
PORT 5001
PORT 5000
PORT 5001

That proves distribution.
